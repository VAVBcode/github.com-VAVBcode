# Portafolio_Digital
Sitio web y perfil personal de desarrollador desplegado en GitHub Pages, destacando proyectos, habilidades y portafolio interactivo.

## Introducción
Este proyecto tiene como objetivo diseñar, construir y desplegar un medio interactivo que refleje la **identidad digital** del desarrollador. A través de este portafolio web desplegado en **GitHub Pages**, se presentan de manera clara, accesible y profesional las habilidades técnicas, proyectos principales y canales de contacto. 

El desarrollo se realiza de forma iterativa mediante fases incrementales, registrando cada avance en el repositorio para que el historial de *commits* certifique la evolución y construcción de la plataforma.


## Resumen de la Fase 1: Observación e Identificación de Requisitos

La primera fase del proyecto se centró en el análisis y estudio comparativo de la comunidad de desarrolladores antes de iniciar la maquetación. Se examinaron las mejores prácticas de documentación, estructuración de perfil y gestión de repositorios para tomar decisiones de diseño fundamentadas.

### Puntos Clave Desarrollados:
- **Análisis de Perfiles de Referencia:** Se compararon tres perfiles destacados de GitHub (`abhisheknaiidu`, `anuraghazra`, `sindresorhus`) bajo criterios de presentación inicial, jerarquía visual, formato de habilidades, selección de proyectos destacados, canales de contacto y accesibilidad móvil.
- **Auditoría de Repositorios Fijados:** Se identificaron las características esenciales de proyectos bien versionados: metadatos completos (descripción, *topics* y demo), archivos base (`LICENSE`, `.gitignore`), estructuración modular de carpetas, historial de *commits* semánticos y uso de características colaborativas (*Issues*, *Pull Requests*, *Releases*).
- **Definición de Requisitos:** Se redactaron los requisitos funcionales (presentación de stack, proyectos destacados, métricas y contacto) y no funcionales (accesibilidad visual, responsividad móvil y mantenibilidad en Markdown) que guiarán el desarrollo del perfil.
- **Diagnóstico y Optimización de Repositorios Propios:** Se aplicó la lista de verificación a los repositorios personales a destacar (`Portafolio_Digital`, `ED_P1_Grupo08`, `landing-page-parque-samanes`, `dashboard`, `dawm-cv`, `ecoruta`), identificando brechas de metadatos, descripciones faltantes y despliegues en vivo a completar en las siguientes fases.
